# PZ Needs Plus

Standalone B42 quality-of-life mod.

Features:
- auto bandage and pain relief outside combat;
- auto eat and drink only outside combat and without a timed action;
- infinite weapon condition;
- infinite ammunition reserve and magazines with normal reload;
- optional instant magazine refill without reloading;
- native Mod Options toggles.

Actions use vanilla timed actions: `ISApplyBandage`, `ISTakePillAction`,
`ISEatFoodAction`, `ISDrinkFluidAction`, `ISReloadWeaponAction`.

Install: copy this folder to `~/Zomboid/mods/PZNeedsPlus`, enable in the save
mod list. No dependencies.
